# PR Writer Skill

## Overview

Creates pull requests with code changes from approved modernization plans. Fork-aware: all operations target `{forkOwner}/{repoName}`, never the upstream repository.

## Interfaces

### FileChange

```typescript
interface FileChange {
  path: string;
  content: string;
  changeType: "create" | "modify" | "delete";
}
```

### PrWriterInput

```typescript
interface PrWriterInput {
  forkOwner: string;          // GitHub user who owns the fork
  repoName: string;           // Repository name
  baseBranch: string;         // Target branch for the PR
  taskId: string;             // Unique task identifier
  taskDescription: string;    // Human-readable task description
  fileChanges: FileChange[];  // Files to create/modify/delete
  artifactIds?: string[];     // Referenced artifact IDs
  riskItems?: Array<{         // Risk assessment items
    id: string;
    severity: string;
    description: string;
  }>;
  recommendations?: string[]; // Planning Agent recommendations
  dryRun?: boolean;           // If true, returns PR details without creating
}
```

### PrWriterOutput

```typescript
interface PrWriterOutput {
  prNumber?: number;          // PR number (only when created)
  prUrl?: string;             // PR URL (only when created)
  branchName: string;         // Generated branch name
  title: string;              // Generated PR title
  body: string;               // Generated PR body markdown
  fileCount: number;          // Number of file changes
  status: "created" | "dry-run" | "failed";
  error?: string;             // Error message on failure
}
```

## Behavior

- Implements `Skill` interface with `name = "pr_writer"`
- Generates branch name: `jurassic/task-{taskId}`
- Generates PR title: `[Jurassic] {taskDescription}`
- Generates PR body with markdown sections:
  - **Changes**: task description and file list
  - **Artifacts Referenced**: listed artifact IDs (if provided)
  - **Risk Items**: table with ID, severity, description (if provided)
  - **Recommendations**: Planning Agent recommendations (if provided)
  - **Footer**: "Generated by Jurassic Modernization Agent"
- In dry-run mode, returns PR details without calling GitHub APIs
- In real mode, calls `createBranch`, `pushFiles`, `createPullRequest` (separate, mockable functions)
- Fork-awareness: all GitHub operations target `{forkOwner}/{repoName}`
- Validates required fields: `forkOwner`, `repoName`, `taskId`, `taskDescription`, `fileChanges`
- Handles empty file changes gracefully
- Catches errors during creation and returns `status: "failed"` with error message
